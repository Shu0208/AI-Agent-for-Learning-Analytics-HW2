# Parking fee

Read one integer duration in minutes (0–1440). Zero minutes is free. Round any started hour up to a whole hour. Charge 30 per hour for hours 1–2, 20 per hour for hours 3–5, and 10 per hour for hour 6 onward. Add the charges across tiers and cap the total at 160 per visit. Print only the integer amount.

Submit one Python 3 file using the standard library. Print no prompts.

## Sample input

```text
61
```

## Sample output

```text
60
```
