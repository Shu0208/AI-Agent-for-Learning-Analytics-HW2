# Score summary

Read 0 to 100 integer scores in the inclusive range 0–100 from standard input. Spaces and newlines separate scores. Print one line with the count, arithmetic mean (exactly two decimal places), and number of passing scores, separated by single spaces. A score of 60 passes. For empty input, print `0 0.00 0`. Count duplicate observations separately.

Submit one Python 3 file using the standard library. Print no prompts.

## Sample input

```text
80 70 90
```

## Sample output

```text
3 80.00 3
```
