# Most frequent word

Read up to 500 ASCII characters from standard input, possibly spanning multiple lines. A word is a maximal run of letters A–Z or a–z. Digits, punctuation and whitespace are separators. Ignore case. Print the most frequent word in lowercase and its count, separated by a single space. Break ties by choosing the alphabetically smallest word. If there are no words, print `NONE 0`.

Submit one Python 3 file using the standard library. Print no prompts.

## Sample input

```text
red red blue
```

## Sample output

```text
red 2
```
